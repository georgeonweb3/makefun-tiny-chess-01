# Tiny Chess — a chess engine in 4,088 bytes of Python (make.fun tiny-chess-01): 0x88 board, alpha-beta search with quiescence, MVV-LVA ordering, fixed 15,000-node budget, no clock, no model calls.
Plays the gauntlet through the env at MAKEFUN_ENV_URL (POST /game, /move) as main.py; MIT licensed, see LICENSE.
